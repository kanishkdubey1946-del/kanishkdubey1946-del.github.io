## ✦ Design System

The portfolio uses a bespoke Material You–inspired dark design system with a `#d2f000` acid-yellow accent, a full Tailwind token configuration, and three typefaces:

- **EB Garamond** — display headings (editorial serif)
- **Hanken Grotesk** — body and UI text (geometric sans)
- **JetBrains Mono** — labels, tags, and meta text (monospace)

---

## ✦ Features

- **Custom cursor** — dot + ring with hover/click states
- **Animated page loader** — progress bar with KAD logotype
- **Particle canvas** — 60 floating particles with connection lines
- **Scroll reveal** — staggered intersection-observer animations
- **Gradient orbs** — floating background glows with CSS keyframes
- **Marquee ticker** — infinite-scroll discipline tags
- **Magnetic buttons** — cursor-follow micro-interaction
- **Skill progress bars** — animated on scroll-enter
- **Auto-hide nav** — hides on scroll-down, reveals on scroll-up
- **AgroBot project modal** — animated overlay with GitHub + live links
- **Film grain overlay** — SVG noise texture at low opacity
- **Mobile full-screen menu** — large serif nav with overlay
- **Active section highlight** — IntersectionObserver-powered nav underline
- **Smooth anchor scroll** — offset-corrected for fixed nav height
