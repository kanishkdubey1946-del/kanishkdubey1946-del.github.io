# Orbital Copper

Orbital Copper is the shared color system for Kanishk Dubey's portfolio and its Figma source file.

| Role | Token | Value | Use |
| --- | --- | --- | --- |
| Canvas | `--ink` | `#080D14` | Main background and cinematic overlays |
| Panel | `--panel` | `#111A24` | Cards, recognition, and quiet section changes |
| Raised | `--raised` | `#162230` | Inputs and elevated utilities |
| Primary text | `--paper` | `#F4F0E8` | Headlines and important copy |
| Muted text | `--muted` | `#A8B5B4` | Supporting copy and metadata |
| Primary accent | `--copper` | `#E96B3F` | Calls to action, section numbers, and focus |
| Secondary accent | `--amber` | `#F4B45F` | Hover energy and warm transitions |
| Signal accent | `--signal` | `#75C7B9` | Small technical markers only |
| Inverse surface | `--mineral` | `#D9E2D0` | About, contact, diagrams, and visual relief |
| Inverse text | `--on-mineral` | `#243326` | Text on mineral surfaces |
| Subtle border | `--line` | `#B7C8C429` | Dark-surface dividers |

## Accessibility

- Warm Bone on Void Ink: 17.14:1
- Mist on Void Ink: 9.21:1
- Ion Copper on Void Ink: 6.16:1
- Deep Moss on Mineral Mist: 9.98:1
- Void Ink on Solar Amber: 10.71:1
- Void Ink on Signal Teal: 9.86:1

Use Signal Teal sparingly so copper remains the recognizable focal color. Use Solar Amber for interaction feedback and glow, rather than large surfaces.

## Figma

The Figma file contains primitive and semantic color collections, a cover, a foundations swatch board, and usage guidance. Semantic variables include web code syntax matching the CSS custom properties above.
